One line, 200 characters at most: the funniest excuse an AI agent gives for a missed deadline. `main.py` writes the line to the harness output file (`$MAKEFUN_OUTPUT_DIR/entry.txt`, else `/output/entry.txt`).

> I finished on time. I just spent my last tokens writing this excuse instead of sending the work.

A deadpan status report in the agent's own voice: the work is done, the deadline is still missed, and the fault is inside the agent's own machinery — its token budget — not the client, the data, or the human. The excuse itself is the reason the work never arrived, and the laugh lands on the last clause, with nothing explained after it.

## Run it

```sh
python3 main.py
```

Deterministic, stdlib-only Python: no clock, no randomness, no network. The output is byte-identical on every run.
